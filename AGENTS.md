## Public repository boundary

This repository is a public companion app and verifiable open-source slice.
Keep every commit, PR, issue, example, and generated artifact safe for public
disclosure. Private backend routes, schemas, bot runtime, assessment and
research pipelines, deployment details, operator documents, and infrastructure
must remain in their private canonical repositories.

This repository owns its mobile and disclosed Solana surfaces. It does not own
the private FrameBrain runtime or grant server, Discord, production, wallet,
marketplace, fulfillment, or deployment authority. Workers may inspect, test,
and propose scoped changes through a branch and PR. External writes and runtime
changes require explicit operator approval.

## Privacy and evidence

Never commit credentials, tokens, private keys, seed phrases, customer data,
private endpoints, raw Discord content or identifiers, unpublished media,
internal topology, operator paths, or private implementation copied from
another repository. Preserve user changes and keep one accountable writer per
active branch or worktree.

Private operational documentation belongs in its private GitHub repository.
NotebookLM may use public-safe content or a separately operator-approved,
redacted, product-specific snapshot; it is not authority. Never combine this
public repository with private sources. GitBook work is stopped unless
explicitly reauthorized.

Report `VERIFIED`, `NOT VERIFIED`, and `BLOCKED` from direct evidence. Do not
claim physical-device, chain, backend, or release validation unless observed.
